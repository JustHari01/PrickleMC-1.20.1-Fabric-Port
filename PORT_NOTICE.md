PrickleMC 1.20.1 Fabric is an unofficial community port by JustHari01 of the 1.21.1 source from [Darkhax-Minecraft/PrickleMC](https://github.com/Darkhax-Minecraft/PrickleMC/tree/1.21.1). The upstream project and its author remain credited; this port is not endorsed by the upstream author.

The upstream repository includes the full GNU Lesser General Public License, version 2.1, in `LICENSE`. This port retains that license and includes its full text in the binary and source distribution. The upstream logo is retained from the licensed source tree.

Port changes target Minecraft 1.20.1 and Java 17, build the shared library against the 1.20.1 mappings, and adapt Minecraft value serialization where 1.20.1 does not provide the newer codecs. The documented Prickle format and property API remain available.

AI tools assisted with the 1.20.1 compatibility changes, tests, and release documentation.
